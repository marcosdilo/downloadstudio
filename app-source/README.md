# Código-fonte

Interface Qt, serviço de monitoramento, regras de organização e testes.

Consulte o [README principal](../README.md) para preparar o ambiente.

- Executar: `python launcher.py`
- Testar: `python test_app.py`
- Compilar: `python build.py`

Requer Windows x64 e Python 3.12. Dependências em `requirements.txt`.
